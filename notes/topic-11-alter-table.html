ALTER Table

Modify table definitions by adding new columns, removing deprecated columns, or changing properties.

Open in Playground Download Script

Concept Overview

The `ALTER TABLE` DDL statement lets you evolve database schemas over time without rebuilding tables from scratch. You can `ADD` new columns with default values, `DROP COLUMN` for deprecated attributes, or alter constraints.

Hands-on SQL Script

11 SQLQuery ALTER.sql 
--ALTER

use google

SELECT * from employee

alter table employee add country varchar(255)

SELECT * from employee

alter table employee add email varchar(255), domain varchar(255), Pincode INT

SELECT * FROM employee

--be carefull while using these command

--we cannot drop any column without alter table

ALTER TABLE employee drop column pincode

SELECT * FROM employee

UPDATE employee set country = 'India'

SELECT * FROM employee
Best Practice: When adding a NOT NULL column to an existing table populated with data, provide a DEFAULT constraint so existing rows receive a valid value.

Execution & Behavior

Column 'department' successfully added to employee table.
