Cloning Tables (SELECT INTO)

Duplicate table schema and data in one step using the powerful SELECT INTO statement.

Open in Playground Download Script

Concept Overview

`SELECT * INTO NewTable FROM ExistingTable` creates a new destination table with matching column names and data types, copying all records. It is minimally logged in bulk-logged or simple recovery models, making it very fast for creating backups or test fixtures.

Hands-on SQL Script

09 SQLQuery Clone.sql 
--Cloning of Table.

USE Google

SELECT * from employee

SELECT * into EMP from employee

SELECT * FROM emp

SELECT * into EMPF from employee where gender = 'Female'

SELECT * from empf

SELECT id, name, age, gender into EMPT from employee

SELECT * from EMPT
Best Practice: To clone ONLY the table structure without copying any data rows, add a false condition: `SELECT * INTO EmptyClone FROM SourceTable WHERE 1 = 0;`.

Execution & Behavior

New table employee_backup created with identical data.
