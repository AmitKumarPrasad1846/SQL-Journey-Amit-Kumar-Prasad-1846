OFFSET-FETCH & STUFF Function

Implement clean server-side pagination with OFFSET-FETCH and manipulate strings with STUFF.

Open in Playground Download Script

Concept Overview

- `OFFSET N ROWS FETCH NEXT M ROWS ONLY`: Standard ANSI SQL syntax for paginating through large result sets. - `STUFF(string, start, length, new_string)`: Deletes a specified length of characters and inserts new text at that position.

--OFFSET FETCH

This is used for paginationretrieving a subset of rows from a query result, 
which is very useful when dealing with large datasets and you want to show 
data in chunks (like in a paginated table on a website).

It means to skip rows ..

Offset - Skips a certain no. of rows
Fetch - Limits the number of rows returned after the offset.
Best Practice: `OFFSET-FETCH` requires an explicit `ORDER BY` clause. It is significantly more efficient and readable than old pagination workarounds.
