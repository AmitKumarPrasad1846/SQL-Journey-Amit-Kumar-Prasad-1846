## 🌟 Overview

**MS SQL Mastery Hub** is a battle-tested, open-source platform designed to take learners from absolute foundational database basics to advanced enterprise T-SQL engineering.

The repository houses **57 modular SQL practice files**, an interactive **in-browser SQL query playground**, automated coding challenges, a **floating glassmorphism rectangular capsule navbar**, and a **7.3 MB comprehensive handcrafted PDF theory manual**.

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 📚 **57 Standalone Lesson Pages** | Dedicated HTML lessons covering syntax, theoretical deep-dives, pro tips, and expected outputs. |
| 🧪 **In-Browser SQL Playground** | Client-side mock relational database runner (`Employees`, `Departments`, `Projects`, `Students`, `Orders`) with live tabular results. |
| ⚡ **Interactive Challenges** | Interview-style SQL problems with real-time query validation, hints, and score tracking. |
| 🧭 **Bottom Glassmorphic Capsule Nav** | Modern floating navigation capsule anchored at the viewport base (`#1EC1CB`, `#1C1C28`, `#FDF4EE`). |
| 📈 **Local Progress Tracker** | Browser-persisted checkbox state tracking completion percentage (0% to 100%). |
| 📥 **Direct PDF Download** | Instant access to the 7.3 MB comprehensive MS SQL manual directly or via Google Drive. |
| 📱 **Zero-Dependency Architecture** | Pure semantic HTML5, Vanilla CSS3, and JavaScript — operates 100% offline without build tools. |

## 🎨 Design System & Palette

The platform adheres strictly to a curated modern dark aesthetic:

- **Primary Accent (`#1EC1CB`)**: Electric Cyan — used for brand highlights, active states, progress indicators, and glowing borders.
- **Surface & Background (`#1C1C28`)**: Slate Obsidian — provides deep, high-contrast dark backgrounds for optimal readability.
- **Typography & High Contrast (`#FDF4EE`)**: Warm Cream — delivers soft, glare-free readability for headings and body content.

## 🚀 Quick Start / Local Setup

No node_modules or compilers needed. Simply launch locally:

### Option 1: Direct Browser
Double-click `index.html` in your file explorer to open in Chrome, Firefox, Edge, or Safari.

### Option 2: Local Python Server (Recommended)
```bash
python -m http.server 3000
```
Then navigate to `http://localhost:3000` in your web browser.
